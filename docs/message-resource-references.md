# 对话引用与文件拖放

对话中的插件、技能和文件引用，与输入框草稿共用 `message-resource-*` 样式。圆角使用 `--radius-card`，字号使用 `--message-font-size`，标签文字字重 600。输入框保留移除按钮，发送后的引用保留查看入口；长名称截断，完整文件路径仍可悬浮查看。

插件图标按来源与能力 ID 获取；技能优先按 SDK 展开的原始技能路径及名称匹配目录元数据，不能根据相同名称借用其他技能图标。没有已声明图标时使用对应资源类型的默认图标。文件沿用文件类型图标，图片保持原有缩略图。

文件引用仅在展示时提取连续的前导 `@path` 或 `@"path with spaces"`；Windows 盘符不视为行号，`:line` 引用及正文不被吞掉。会话原文、复制和编辑所需路径仍保留，无需重写历史文件。

桌面端使用当前 Webview 的原生拖放事件，将落在可见输入框内的路径交给现有附件 API。按设备像素比例判断落点，隐藏会话、弹窗覆盖区域和输入框外不接收。图片作为图片附件，其他文件和文件夹作为引用。切换草稿后忽略旧请求的迟到结果；卸载组件时释放原生事件监听。浏览器端通过普通文件拖放复用同一附件处理流程。

验收：从资源管理器拖入文件、多个文件、文件夹及图片；核对缩放下的落点、拖出取消、会话切换、隐藏会话及菜单覆盖。原生事件分发、缩放坐标与迟到监听清理由 `lib/composer-drop.test.mjs` 覆盖；资源解析与图标身份由 `lib/message-resources.test.mjs` 覆盖。
