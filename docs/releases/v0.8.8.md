## 中文

- 统一 Eureka 网页端、桌面端及安装包版本为 0.8.8。
- 接入签名更新：检查新版本、后台下载、进度显示和安装前验证。
- 在左侧头像上方增加更新入口，并加入“帮助 → 检查更新”。
- 安装前检查聊天和自动化任务，退出时清理本地服务及子进程。
- 更新窗口支持中文、英文、浅色和深色模式。
- 发布包仅保留公开登录配置；本机会话密钥独立生成并跨升级保留。

首次安装包含更新器的版本需要手动下载安装包。后续版本可通过应用内更新。
从旧安装包首次迁移到本机会话密钥时，可能需要重新登录；之后的升级会沿用该密钥。

## English

- Unified web, desktop and installer versions at 0.8.8.
- Added signed updates with version checks, background downloads, progress and verification.
- Added an update button above the account avatar and Help → Check for updates.
- Added active-task checks before installation and local process cleanup on exit.
- Added Chinese/English translations and light/dark update dialogs.
- Bundled only public login configuration; session encryption keys are generated locally and retained across updates.

Install this updater-enabled version manually once. Later versions can update in-app.
Migrating from an older installer may require signing in again once; subsequent updates retain the local session key.
