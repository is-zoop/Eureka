## 中文

Eureka 0.9.0 主要升级自动化 SDK 至 **1.3.0**，并将 PI SDK 相关组件统一升级至 **1.5.0**，补齐自动化执行、模型接入与桌面运行的兼容能力。

### 自动化 SDK 1.3.0

- **统一能力契约**：应用声明、方法和关键限制使用同一份 SDK 契约；同步提供 Haze 对接文件、校验器和兼容样例。
- **文件与报表能力**：新增分块文件读写、流式下载、CSV/XLSX 表格服务和文件产物；支持授权范围内的大文件操作，流式下载及单文件产物最高 1 GiB，按原字节另存为，减少 Base64 和整文件内存中转。
- **浏览器与接口能力**：完善登录态复用、授权请求、接口凭证引用及文件上传；凭证保存在本机，接口凭证采用 Windows DPAPI 加密，脚本不直接取得凭证。扩展请求控制、定位与任务页面恢复能力。
- **业务 AI 配置**：每个应用独立选择运行模型、推理强度、超时和输出上限；新增独立分类模型，支持是/否、选项和评分规则，保留原有聊天 AI 规则。
- **本地定时运行**：支持一次、每天、每周和固定间隔，提供暂停、启用、删除及下次运行时间。计划固定应用版本、功能和参数，动态日期按触发时重新计算。
- **应用与本地工作区**：完善多功能应用、配置和运行记录隔离、应用信息与图标编辑，以及 Haze 上传和发布流程。本地创建与执行不再依赖 Haze 登录，保留原有数据命名空间，不搬移或合并网站凭证。
- **创建体验修复**：支持读取用户在当前任务中明确提供的原项目路径；补齐分类规则模板和字段校验信息，写入失败直接显示实际错误，减少反复生成无效文件。

### PI SDK 1.5.0

- **模型与认证兼容**：统一升级 PI 的 agent、AI、coding-agent、MCP 和 TUI 组件；适配模型目录、扩展服务商、API Key/OAuth 状态及模型范围解析，支持已安装的 WorkBuddy 等服务商扩展。
- **原生 MCP**：接入 SDK 原生 MCP、工具搜索与 Codemode；服务商配置支持直接提供、按需搜索和 Codemode 调用。Haze 保留逐请求凭证与身份、权限、地址校验。
- **Windows 命令环境**：通用设置新增 Bash / PowerShell 选择，影响新会话；原有会话和权限等级保持独立。
- **等待与上下文兼容**：同步 SDK 等待用户状态、取消和恢复；适配上下文编辑记录、压缩及分支用量，修复发送消息后重复出现用户气泡的问题。
- **缓存预热**：提供关闭、仅运行期间、运行与空闲期间三种模式；上下文用量中显示 SDK 状态及已有预热费用，不重复计入会话总额。
- **扩展更新说明**：插件详情页下方提供“安装详情 / 更新说明”切换，统一固定高度容器、字体和间距；按需读取包内说明并保留已读状态。
- **对话生成图片首版**：通过明确的对话请求调用独立图片模型，生成后直接预览、放大和另存为；图片引用随会话保存。每轮最多一次生成尝试，不自动重试，不改变主聊天模型。

### 升级与使用边界

- **原生 MCP 不自动迁移旧适配器配置或转换历史工具格式**。旧配置需在新的 MCP 设置中重新接入；已有原生配置不批量更改工具提供方式。
- 定时计划只在 Eureka 运行且电脑未休眠时触发；错过不补跑、上一轮未完成则跳过。浏览器登录、验证码和授权仍可能需要人工处理。
- 图片生成需要可用的图片服务商凭证。当前 SDK 内置图片适配器为 OpenRouter，也支持全局扩展提供的图片模型；能使用 ChatGPT/Codex 聊天不代表具备图片 API 权限。首版不包含图片编辑、批量生成或自动化图片节点。
- 在线 AI、图片生成及缓存预热可能产生费用；缓存预热按 SDK 支持情况及成本判断触发，不保证所有模型都会预热或一定节省费用。
- 请求诊断和工具实时进度目前暂不启用；保留原有处理详情与最终工具结果。分类模型仍仅用于自动化，不对普通对话开放分类工具。
- 原生文件、浏览器和凭证能力需更新桌面安装包后使用。Haze 云端发布需部署匹配契约与接口；本版本包含对接文件，不代表已更新 Haze 服务端。

## English

Eureka 0.9.0 upgrades the **Automation SDK to 1.3.0** and all PI SDK components to **1.5.0**.

### Automation SDK

- Unified capability contracts, validation fixtures and Haze integration files.
- Chunked file I/O, streamed downloads, CSV/XLSX services and binary artifacts, with authorized downloads and individual file artifacts up to 1 GiB.
- Improved browser-session reuse, authorized API requests, scoped encrypted credential references and file uploads.
- Per-application AI settings and dedicated boolean, choice and score classifiers, preserving existing chat-based rules.
- Local one-off, daily, weekly and interval schedules with pinned versions/actions/parameters, relative dates and pause/resume controls.
- Improved multi-action applications, metadata/icon editing and Haze publication. Local authoring and execution remain independent of cloud login without relocating private data.
- Read-only access to original source paths explicitly supplied by the user, complete classifier templates and actionable authoring validation errors.

### PI SDK and desktop integration

- PI agent, AI, coding-agent, MCP and TUI packages upgraded to 1.5.0, including provider-extension, authentication, model-catalog and model-scope compatibility.
- Native MCP, tool search and Codemode exposure controls, preserving Haze's per-request credential and authorization checks.
- Bash/PowerShell selection for new Windows sessions; improved user-wait, cancellation, context, compaction and branch handling; fixed duplicate user-message rendering.
- Cache-warming controls and status, without double-counting warming costs.
- On-demand package release notes alongside installation details in consistent, bounded panels.
- Chat-triggered single-image generation with a separate image model, inline preview, Save As and persisted image references. One attempt per run, no automatic retry, no chat-model switch.

### Compatibility notes

- Legacy MCP adapter configuration and historical tool formats are not automatically migrated. Reconfigure those servers through native MCP settings.
- Local schedules require Eureka to be running and the computer awake. Missed runs are not replayed; overlapping runs are skipped. Browser authentication may still require user assistance.
- Image generation requires image-provider access. The installed SDK includes OpenRouter image support; global extensions may add other providers. ChatGPT/Codex chat access alone does not establish image API access. Image editing, batches and automation image nodes are outside this release.
- AI, images and cache warming may incur charges. Warming depends on SDK support and cost decisions and does not guarantee savings.
- Request diagnostics and live tool-progress features remain disabled. Dedicated classifiers remain automation-only.
- Native capabilities require the updated desktop application. Haze publishing requires matching server-side contracts and endpoints; bundled integration files do not deploy the Haze server.
