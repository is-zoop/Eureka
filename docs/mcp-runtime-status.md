# MCP 运行状态

点击对话底部的 MCP 状态文字，查看当前会话的服务快照。面板打开时每三秒读取一次，支持手动刷新；关闭面板、切换对话或页面进入后台时停止读取。查看状态不会启动会话、连接 MCP 或触发模型调用。

手动刷新时按钮显示旋转图标和“刷新中…”，并暂时禁用重复点击。读取成功后短暂显示“已刷新”，即使快照没有变化也给出反馈；读取失败显示“刷新失败”及错误提示。自动轮询不触发这组手动操作提示。

展示已启用、已连接、工具总数及已知资源数，并逐个列出服务名称、连接状态、工具数、直接注册工具数、资源数、通知监听状态、目录过期提示和失败距快照生成的时间。界面不展示顶部说明段落及底部快照更新时间；刷新仅重新读取当前快照，不改变服务连接。

- “目录已缓存”表示有工具目录，但当前没有活动连接；“未连接”可能表示尚未首次调用或空闲断开，均不等于故障。
- 已停用服务会明确标记。新安装或修改的配置仍遵循当前会话的重载规则。
- 工具数来自适配器目录及注册信息，不代表当前工具权限已开放；完全禁用工具时不会因查看状态而恢复权限。
- 当前会话的工具权限从顶部会话菜单进入，支持禁用、只读、默认及全部四种预设；系统设置中的“常规”卡片将语言与新会话默认工具权限合并为两行下拉设置。新会话初始使用“默认”，与旧版记录的上次会话权限分开保存；用户在设置中明确选择后才改变之后新会话的默认值。会话修改只作用于当前会话，新会话默认值仅作用于本设备之后创建的会话。运行中修改会排队，计划流程期间权限保持锁定。底部不再常驻权限选择和压缩按钮；手动压缩通过 `compact` 命令，压缩过程中可从“＋”菜单停止压缩。
- 适配器未提供的资源数等字段显示 `—`。没有运行快照时显示无快照提示，不推断为已连接。
- 当前公开快照没有详细错误文本、请求延迟、调用成功率、连接地址、配置来源、生命周期策略或认证凭证。面板仅根据状态提供解释，不伪造这些信息，不读取或展示密钥、环境变量、请求头及启动链接。

状态收集器在会话开始前订阅适配器事件，暂存最初快照，在会话 ID 就绪后归档；退出或重载时释放旧订阅及快照。不同对话分别保存和读取，面板不把上一对话的结果带入下一对话。
