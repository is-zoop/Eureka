# 自动化下载与导出：选择保存路径

2026-10-31：自动化文件改为“另存为”，等待用户编译、验收。

## 行为

- 结果面板“下载 → 完整结果 JSON”、真实生成的 CSV／JSON 等产物、侧栏应用菜单的“导出应用包”统一使用 `saveFileAs`。
- Eureka 桌面中显示 Windows 系统“另存为”窗口，可选择目录和文件名；覆盖已存在文件由系统确认。取消不写文件，也不显示提示。
- 不添加成功横幅、消息卡片或保存路径提示。仅保存失败使用原有错误区域；保存动作不重跑查询或应用。
- 桌面端复用附件选择模块的 COM 文件对话框，新增 `desktop_save_file`，仅本机 Eureka 内容视图可调用。前端只传建议文件名和二进制内容，不能传目标路径；路径必须由系统对话框选择，返回值只表示保存／取消，不回传本机路径。
- 二进制传输保留原文件字节，支持当前最多 16 MiB 的产物及 20 MiB 应用包，保存通道上限为 32 MiB。写入同目录临时文件后再替换目标，失败尽量移除临时文件，不先截断已有文件。
- 普通网页使用浏览器原生保存选择器，并在数据请求前调用以保留用户点击授权。不支持该能力的浏览器不回退成静默下载。
- 新增权限只授予 `eureka-content`，不授予网站子视图。原网站直接下载的范围没有扩大。其他页面的既有下载入口不在本轮自动化调整范围内。

## 用户编译与验收

需要重新编译桌面程序。先退出 Eureka，避免 EXE 占用；重启根目录开发服务，再自行执行：

```powershell
cd E:\Eureka\desktop
.\node_modules\.bin\tauri.cmd build --debug --no-bundle --config src-tauri/tauri.dev.conf.json
```

打开 `E:\Eureka\desktop\src-tauri\target\debug\eureka.exe` 后检查：

1. 在已完成的实际运行中选择“完整结果 JSON”，确认系统出现另存为窗口，可修改文件名、选择目录；保存后到所选位置检查文件可打开，界面没有额外成功提示。
2. 分别保存已有 CSV 和 JSON 产物，确认文件内容、中文、编号与原结果一致；不触发新的运行。
3. 在应用条目的“…”菜单导出 ZIP，选择保存位置，确认文件可用于原有导入预览。
4. 取消另存为窗口，不应产生目标文件或报错提示；再次选择保存仍可正常使用。覆盖测试文件时先检查系统确认，再选择取消和确认。
5. 使用无写入权限的测试位置验证保存失败仍能显示实际错误；不要覆盖日常重要文件进行验证。
