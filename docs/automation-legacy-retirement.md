# 旧版内置商品查询下线

2026-10-31：用户要求删除已过时的内置工具代码，后续只使用独立应用包。

## 已移除

- “已有查询工具”侧边栏、旧详情和固定节点画布、旧创建页及浏览器设置弹层。
- 商品专用生成器、固定商品字段及编号数量约束、旧工具库、旧聊天调用与回传。
- 旧版 draft、tool、library、invocations、creation、observe、research、browser 接口与专用演示页面。
- 原生录制／请求复查／商品查询命令、网络证据及商品字段比较模块，以及相应脚本、权限和专用测试源码。

## 保留的共用能力

首页现有 Pi loop、“自动化”命令、应用生成和校验、独立应用包及其运行器、动态画布、日志和产物继续保留。浏览器的通用 DOM 观察、声明操作、账号和输入控制由独立应用使用。账号命令通过新的 `/api/automation/identity` 检查当前用户，不再读取旧草稿。

旧创建会话只保留识别、访问隔离和只读保护，不加载旧扩展、不恢复旧任务执行。新任务不再接受旧 `baseTool` 引用；已保存独立应用通过 `baseApp` 修改版本。

本次只删除项目源码。旧工具用户数据、浏览器登录、已保存独立应用包及用户配置未删除；不把旧工具转换成新应用。

## 用户操作与验收

本轮修改原生代码，需要重新编译桌面程序。先退出正在运行的 Eureka，避免 `eureka.exe` 被占用；根目录开发服务重启后执行：

```powershell
cd E:\Eureka\desktop
.\node_modules\.bin\tauri.cmd build --debug --no-bundle --config src-tauri/tauri.dev.conf.json
```

打开新生成的 `E:\Eureka\desktop\src-tauri\target\debug\eureka.exe` 后检查：

1. 自动化目录只显示独立应用，“已有查询工具／商品查询”入口消失；原“千牛商品批量查询”仍能打开。
2. 用已成功的参数运行原独立应用，确认登录复用、实际节点、结果、下载与停止正常。
3. 首页 `/automation` 仍可创建独立应用，保存后可从目录打开，“用 AI 修改”仍关联原独立应用版本。
4. 普通会话及原有 Skill／HTTP MCP 企业插件可用；旧创建会话可查看，不能恢复旧商品工具执行。

开发者只进行了源码与引用检查，没有运行编译、类型检查、测试、模型调用或真实网页验证。
