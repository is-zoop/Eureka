# 自动化运行页：画布优先

2026-10-31：用户选择交互预览中的“画布优先”布局。本轮修改页面及版本使用策略，等待用户验收。

## 页面范围

- “另存应用”仅显示在市场应用的菜单中，用于创建可独立修改的个人副本；我的应用直接使用“AI修改”，不显示“另存应用”。

- 运行页占满当前内容区，页面本身不向下滚动。左侧是动态流程画布，右侧用标签页切换结果和日志；这些模块各自滚动。内容区变窄时，结果模块移至画布下方，仍留在当前屏幕内。
- 左右模块之间加入可拖动分割线，复用现有面板拖拽 hook。右侧最小 280px、左侧最小 320px；拖动、方向键可调整，双击／Enter 恢复默认宽度。当前用户的调整后宽度保存在本机，同一用户的应用共用；缩窄窗口或打开浏览器侧栏时重新约束，窄布局隐藏分割线并维持上下排列。拖动不派发业务动作，不重新运行应用。
- 后续样式调整：分割线参考首页面板边界，始终为 1px，悬停、聚焦及拖动使用同款灰色 `#b8b7b7`，不再使用亮色加粗。侧栏应用不再附加版本及启停文案，条目右侧提供“…”应用菜单。
- 点击节点在画布内打开详情，输入／输出、重复执行记录在详情中查看。跟随执行只滚动画布模块；查看日志和节点不会派发业务动作。
- 参数、文件选择、浏览环境和持续授权放入配置弹窗。参数与浏览环境使用各自的保存操作；关闭弹窗不会声称撤销已经完成的文件授权。
- 浏览环境页进一步精简：默认仅展示网站名称／域名、环境选择及“保存”按钮；不再显示重复标题、使用说明、路径／变更数量、暂无授权提示或成功横幅。存在有效授权时才显示默认收起的授权入口，展开后可查看及撤销。保存通过按钮“已保存”反馈；读取配置期间禁用选择和保存，防止覆盖尚未载入的配置。首次操作授权和真实错误提示仍保留。
- 主操作合并为开始／停止；多个应用按钮通过运行方式菜单选择。结果 JSON 和实际产物通过同一个下载菜单提供，不固定业务字段或输出格式。
- 下载和应用包导出统一显示系统“另存为”，用户选择路径；取消静默处理，不添加成功提示。此能力新增原生命令，需要用户按[保存路径验收](./automation-save-as.md)重新编译；不触发业务重新执行。
- 运行区顶部不再显示“更多”。运行记录、重新读取、应用信息、AI 修改、导出、启停及卸载移到左侧对应应用的“…”下拉菜单；信息与确认弹窗保持原样。菜单在当前应用运行、启动待确认或读取运行期间禁用，动作携带目标应用 ID 并核对当前视图，避免切换后操作错应用。版本、能力、代码目录、数据目录、流程声明和 README 不常驻运行页。
- 登录协助、网页变更授权和实际异常仍然可见。等待协助时打开画布内的处理面板；不使用会中断原生浏览器控制的模态弹窗。执行中禁用配置及管理菜单，保留停止、节点详情和结果／日志切换。
- 使用现有 Button、Card、Tabs、DropdownMenu、Input、Textarea 等组件，并在公共组件目录补充 Dialog。后续创建卡片改为字段摘要及按需展开的同一个运行面板，移除紧凑预览分支；预览仅观察本任务的真实试运行，详见[创建卡片](./automation-authoring-ui.md)。

## 最新版本策略

移除版本切换入口和公开 activate 操作。打开目录／应用时，将原来选中的历史版本迁移至已安装的最高版本，更新登记修订号；导入低版本会被拒绝。同版本仍须代码摘要一致，新代码必须提升版本号。

旧版本文件、用户数据及运行历史不删除。已经启动的任务使用启动时的代码快照，不在运行中替换代码；之后的新任务使用最新版本。历史运行可查看结果，不用于回滚应用。

## 用户验收

### 2026-11-02：查看详情复用扩展侧栏（v0.81）

应用菜单“应用信息”更名“查看详情”，移除原居中信息弹窗。使用 AppShell 已有的组织扩展右侧浮层和宽度调整；两处详情共用 `ExtensionDetailsPanel` 的标题、图标、标签页、滚动区域、卡片字段和底部操作布局。

- 市场应用读取实际插件市场记录并直接使用 `OrganizationExtensionDetails`，保留原插件图标、详情、快速开始、文档、收藏与既有管理入口。先核对实际仍安装的来源范围，避免过期来源记录导致显示错误安装状态。
- 本地应用使用同一详情框架，只显示已保存的版本、状态、更新时间、说明、能力、参数与流程；README 使用现有 Markdown 展示。不编造开发者、部门或调用次数。市场暂不可读时回退到本机已安装信息。
- 原有代码路径、数据路径和发布文件收进折叠区域；清理按钮按用户后续要求移至应用下拉菜单最底部，统一命名“清理用户数据”。本地与市场应用均可使用，仍由原应用管理器校验目标应用及执行状态，并二次确认；本次只移动入口，不执行清理，未运行测试。

用户刷新后验收：本地与市场应用的“查看详情”从右侧展开；三个标签页可切换；市场页信息与组织扩展一致；侧栏可调宽及关闭；目标网页打开时详情按钮仍可点；数据清理仍先确认；组织扩展原详情页继续可用。本轮未运行编译、测试或真实安装／网页验证。

### 2026-11-02：运行记录固定按开始时间倒序（v0.80）

服务端以运行记录的 `startedAt` 选择最近 30 条，不再使用目录修改时间；前端加载、轮询更新及新运行接入使用同一排序规则。查看旧记录或状态更新只替换内容，不把条目移动至列表顶部；同一开始时间使用运行 ID 确定稳定顺序。只有新运行开始时新增相应条目，不按成功、失败、已停止等状态分组。没有写入运行记录的准备目录不参与排序。

当前查看的记录按运行 ID 显示选中底色及勾选标记，并提供 `aria-current`；状态文字保留各自颜色。切换记录后重开列表，标记随当前记录更新，不调整条目顺序。仅界面改动，未运行测试。

用户刷新后打开运行记录，选择较旧条目，再次打开列表及刷新页面，应始终最新在上、顺序不变。状态颜色继续保留。本次未运行编译、测试或真实任务，无需原生编译。
