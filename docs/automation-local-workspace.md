# 本地自动化与云端登录

“设置 → 自动化管理”统一显示 AI 资料生成、浏览器管理、卸载后保留的数据。原浏览器设置入口归入此页；旧 browser 页面定位映射到自动化管理。浏览器管理以下拉选择默认或独立环境，只展示所选环境的管理菜单和密码保存开关，操作仍绑定该环境及当前本地工作区。卸载后保留的数据使用单独容器，按前五项实际高度限制展示区域，更多应用通过容器滚动访问。

自动化创建、修改、导入、导出、配置和运行属于当前系统用户的本地工作区。登录页选择“跳过登录”即可使用。Haze 退出、过期或切换账号不会更换本地工作区，也不会因此停止已开始的本地运行。模型服务和目标网站本身需要的凭证仍按各自要求提供。

## 本地上下文

`features/automation/runtime/automation-local-context.ts` 在 agent 目录保存 `eureka-local-automation.json`，包含随机 `workspaceId` 和存储命名空间 `ownerKey`，不含登录凭证。首次初始化使用完整临时文件及不可覆盖的链接发布，避免多个进程初始化出不同上下文。

API 保留原有 `ownerKey`、`runtimeId` 字段以兼容前端和原生浏览器；本地接口中的 `runtimeId` 现在是持久化的 `workspaceId`，不是 Haze 登录代次。重置工作区仍会使旧操作失效。运行还保留进程、租约、版本、停止状态、文件授权和网页操作授权校验。

`automationTaskOwner()` 为创建任务、仅选择本地应用的聊天及其排队请求绑定本地工作区。问题回答和继续执行沿用这个绑定。混合选择组织插件的聊天仍检查那些插件的云端身份与权限。

## 原有数据

`LocalAutomationAppStore` 汇总当前 agent 目录下已有的 `app-data/<64位命名空间>`，按应用实际位置访问原包、配置、文件授权和日志，不复制或删除旧目录。首次初始化复用一个已有命名空间，避免单一旧目录的应用和网页账号换地址。旧任务引用在读取时关联本地工作区；仅查看历史不会重写会话文件或 `task.json`。

旧目录中存在同 UUID 的应用或任务时，保留全部原记录并报冲突，不自动覆盖或合并。目录联接和符号链接不参与发现。网页账号的本地资料继续保留各自目录；不会自动合并不同旧命名空间中的浏览器凭证。

新下载的市场自动化投影也使用本地目录。切换云端账号不重复创建同一安装。组织插件的启用、停用和卸载来源校验仍生效；停用后撤销执行权限。

## 云端操作

发布市场应用、组织插件管理和企业 MCP 继续使用 `hazeAutomationAccess()` 及各服务原有权限校验。发布窗口另外固定 `cloudSessionId`，提交时检查当前云端登录，避免切换账号后将已打开窗口的内容发给另一账号。发布记录按云端 issuer/subject 隔离。

本地编辑可使用已缓存分类和当前应用分类；云端分类刷新失败不会禁用编辑。退出登录保留访客入口并在原页面更新账号显示，不跳转或卸载本地工作区。

## 目录加载

应用列表先调用 `/api/automation/apps` 显示本地登记；登录用户再后台调用 `?sync=1` 刷新组织安装状态。同步错误不清空已经显示的本地列表。切换选中的应用不再触发全目录刷新，导入、管理操作和手动刷新仍会更新列表。正常版本无需迁移时，`useLatest()` 不获取登记文件写锁；安装、启动、停用与代码完整性检查继续使用原有保护。

扩展市场仅缓存展示目录（30 秒）和分类（5 分钟）。缓存键包含 issuer 与访问令牌的哈希，不保存原始令牌；最多 32 条、序列化数据预算 8 MiB。每次请求仍先验证当前登录及权限，手动刷新绕过已完成缓存，收藏变更立即失效当前身份目录缓存。分类和目录的云端读取有 12 秒请求超时。

同时发生的目录、分类、图标鉴权可合并同一登录的 `userInfo` 调用；该结果 TTL 为零，只复用尚未完成的请求，不复用已完成的权限结论。安装、运行或停用权限不从展示缓存读取。这些优化在开发模式和正式包中均生效，不取消开发模式的首次编译。

## 加载回归验证

`tests/extensions/extension-catalog-cache.test.mjs` 和 `tests/extensions/extension-catalog-routes.test.mjs` 覆盖请求合并、TTL、容量预算、手动刷新、收藏失效、账号/issuer 隔离及缓存命中后的权限撤销。正常目录读取在登记文件已被其他写入锁定时仍可完成。

`tests/automation/automation-local.integration.test.mjs` 使用隔离临时目录，覆盖旧目录读取与修改、旧任务恢复、真实本地 worker、聊天逐步执行、云端登录变化、工作区重置、同 ID 冲突、目录联接拒绝以及未登录不能发布。测试不调用真实模型、业务网站或云端发布接口。
